## 3. Problem and solution

**Problem**

- Founders get cheap MVPs that skip payments, admin, and ops, then pay a rewrite tax.
- Agencies add margin and handoffs; fractional CTOs often do not ship code weekly.
- After launch, nobody owns incidents, integrations, and roadmap velocity.

**Solution**

- Scoped builds using published ZAR bands (2026 guide on site).
- Post-launch **monthly retainers** tiered by operational load (Essential / Growth / Ecosystem).
- Same senior engineer from architecture through maintenance.
